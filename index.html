Fórmulas Básicas de Integración

  1. 1 ∫ k dx = kx + C
  2. 2 ∫ xn dx = xn+1 n+1 + C, n ≠ -1
  3. 3 ∫ 1 x dx = ln|x| + C
  4. 4 ∫ ex dx = ex + C
  5. 5 ∫ ax dx = ax ln a + C, a > 0 ∧ a ≠ 1
  6. 6 ∫ sin x dx = -cos x + C
  7. 7 ∫ cos x dx = sin x + C
  8. 8 ∫ sec2 x dx = tan x + C
  9. 9 ∫ csc2 x dx = -cot x + C
  10. 10 ∫ sec x tan x dx = sec x + C
  11. 11 ∫ csc x cot x dx = -csc x + C
  12. 12 ∫ tan x dx = -ln|cos x| + C
  13. 13 ∫ cot x dx = ln|sin x| + C
  14. 14 ∫ csc x dx = ln|csc x - cot x| + C
  15. 15 ∫ sec x dx = ln|sec x + tan x| + C
  16. 16 ∫ sinh x dx = cosh x + C
  17. 17 ∫ cosh x dx = sinh x + C
  18. 18 ∫ 1 √(a²-x²) dx = sin-1(x/a) + C
  19. 19 ∫ 1 a²+x² dx = 1 a tan-1(x/a) + C
  20. 20 ∫ 1 x√(x²-a²) dx = 1 a sec-1|x/a| + C

  22. 22

    = cosh-1(x/a) + C, a > 0
  23. 23
