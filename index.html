Fórmulas Básicas de Integración

  1. \[ \int k\,dx = kx + C \]
  2. \[ \int x^n\,dx = \frac{x^{n+1}}{n+1} + C, \quad n \ne -1 \]
  3. \[ \int \frac{dx}{x} = \ln \left| x \right| + C \]
  4. \[ \int e^x\,dx = e^x + C \]
  5. \[ \int a^x\,dx = \frac{a^x}{\ln a} + C, \quad a>0 \wedge a \ne 1 \]
  6. \[ \int \sin x\,dx = -\cos x + C \]
  7. \[ \int \cos x\,dx = \sin x + C \]
  8. \[ \int \sec^2 x\,dx = \tan x + C \]
  9. \[ \int \csc^2 x\,dx = -\cot x + C \]
  10. \[ \int \sec x \tan x \,dx = \sec x + C \]
  11. \[ \int \csc x \cot x\,dx = -\csc x + C \]
  12. \[ \int \tan x \,dx = -\ln \left| \cos x \right| + C \]
  13. \[ \int \cot x\, dx = \ln\left|\sin x \right| + C \]
  14. \[ \int \csc x\, dx = \ln\left|\csc x - \cot x \right| + C \]
  15. \[ \int \sec x \,dx = \ln\left|\sec x + \tan x \right| + C \]
  16. \[ \int \sinh x \,dx = \cosh x + C \]
  17. \[ \int \cosh x\, dx = \sinh x + C \]
  18. \[ \int \frac{dx}{\sqrt{a^2-x^2}} = \sin^{-1}\left(\frac{x}{a}\right) + C \]
  19. \[ \int \frac{dx}{a^2+x^2} = \frac{1}{a}\tan^{-1}\left(\frac{x}{a}\right) + C \]
  20. \[ \int \frac{dx}{x\sqrt{x^2-a^2}} = \frac{1}{a}\sec^{-1}\left| \frac{x}{a}\right| + C \]
  21. \[ \int \frac{dx}{\sqrt{a^2+x^2}} = \ln\left|x+\sqrt{a^2+x^2} \right| + C \]
    \[ = \sinh^{-1}\left(\frac{x}{a}\right) + C, \quad a>0 \]
  22. \[ \int \frac{dx}{\sqrt{x^2-a^2}} = \ln\left|x+\sqrt{x^2-a^2} \right| + C \]
    \[ = \cosh^{-1}\left(\frac{x}{a}\right) + C, \quad a>0 \]
  23. \[ \int \frac{dx}{x^2-a^2} = \frac{1}{2a}\ln\left|\frac{x-a}{x+a} \right| + C, \quad a>0 \]
  24. \[ \int f(ax+b)\, dx = \frac{1}{a} \int f(u) \,du \]
    \[ \text{con } u=ax+b \wedge a\ne 0 \]
